## Known Issues (Pre-existing)

### Already Committed Files
The following files/directories are already tracked in git but should typically be ignored:

1. **`frontend/android/.gradle/`** - Build cache directory (entire directory tree is committed)
2. **`frontend/android/gradlew`** - Gradle wrapper script (intentionally committed per Flutter convention)
3. **`frontend/android/gradlew.bat`** - Gradle wrapper batch file (intentionally committed per Flutter convention)
4. **`frontend/android/local.properties`** - Local Android SDK path (should be user-specific but is committed)

These files were committed before the .gitignore patterns were added. The .gitignore will prevent NEW files from being added, but won't remove already-tracked files.

### Recommended Actions (Optional)
To remove these tracked files (if needed):
```bash
# Remove .gradle cache from git (if desired)
git rm -r --cached frontend/android/.gradle

# Remove local.properties from git (if desired)  
git rm --cached frontend/android/local.properties
```

**Note**: For Flutter projects, `gradlew` and `gradlew.bat` are often intentionally committed to ensure consistent Gradle wrapper versions across the team. The current setup follows this convention.
